# n8n workflow templates

This directory contains the orchestration blueprints for the AI Video Factory automation pipeline. Each workflow is meant to be imported into n8n and connected to the API and storage components.

The following workflows are defined:

1. Workflow 01: Telegram Input Handler
2. Workflow 02: Research and Script
3. Workflow 03: Storyboard
4. Workflow 04: Visual Generation
5. Workflow 05: Voice Generation
6. Workflow 06: Video Rendering
7. Workflow 07: Delivery
8. Workflow 08: Social Publishing
9. Workflow 09: Error Recovery
